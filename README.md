# CXM Intelligence Hub

CRM, AI lead scoring and customer intelligence dashboard tailored for a technology consulting internship application.

## Why this project fits the FocalCXM Technology Stream

The project is designed around the skills mentioned in the role:

- Python and SQL thinking through data cleaning, scoring and query logic
- Power BI-style dashboard reporting
- AI lead scoring and next-best-action recommendations
- Salesforce-style CRM pipeline workflow
- API, Azure and Snowflake integration positioning
- Business consulting output through a generated proposal outline

## Features

- CRM filters by account, owner, industry, pipeline stage, segment and AI score
- AI-style lead scoring based on revenue, probability, urgency, service pain and data quality
- Data quality checks for duplicate records, invalid emails, stale contacts and high support volume
- Salesforce-style pipeline view
- Revenue trend visualisation
- Customer segment and technology opportunity charts
- Account table with risks and next action
- SQL-style query logic panel
- Generative AI proposal assistant
- CSV import and scored CSV export

## Portfolio positioning

This is a front-end portfolio project with realistic CRM data and transparent scoring logic. It is not connected to a live client CRM. It is suitable for demonstrating how a student can translate business data into a practical technology consulting workflow.

## Run locally

Open `index.html` directly, or serve this folder with a simple local server:

```powershell
python -m http.server 8794 --bind 127.0.0.1
```
